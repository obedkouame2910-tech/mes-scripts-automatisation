# Python Automation & Processing Scripts

A collection of clean, efficient, and ready-to-use Python scripts for everyday tasks:

- **File Organizer:** Automatically categorizes files by format into specific folders.
- **Text Cleaner:** Cleans, formats, and removes duplicates from raw text data.
- **CSV to JSON Converter:** Seamlessly converts tabular data files into web-ready JSON format.

## Technologies Used
- Python 3
